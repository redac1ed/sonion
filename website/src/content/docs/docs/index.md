`sonion` is a recreation of the World Wide Web (WWW), with sites on normal addresses like `hell.son` and `meow.balls`. It houses its own protocol, registry, server and browser.


## Where to go next

- Install the browser and CLI from [here](/docs/install/).
- Host your first site (with help from [here](/docs/host-a-site/)).
- Checking out other sites by opening `sonion://domains.son/#/sites` in the browser.
